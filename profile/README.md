## Inside QualCoder

QualCoder is a local Windows coding app with a named coder desk, a short code list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside sources you already keep and holds only the case that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra piles wait for their own title. QualCoder starts with a local profile and does not need a complex account system.
